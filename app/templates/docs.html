Developer Integration Documentation

Everything you need to run Falsegreen locally, in CI pipelines, and with GitHub Actions.

1. CLI Quickstart Installation

Install the Falsegreen CLI locally via pip:

pip install falsegreen
falsegreen .                          # scan current directory
falsegreen tests/ --fail-under 90     # fail CI if Trust Score drops below 90%
falsegreen . --format sarif -o report.sarif # export OASIS SARIF v2.1.0

2. GitHub Actions CI/CD Integration

Add Falsegreen to your repository workflow (.github/workflows/falsegreen.yml):

name: Falsegreen Test Trust Gate

on: [push, pull_request]

jobs:
  verify:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-python@v5
        with:
          python-version: "3.12"
      - run: pip install falsegreen
      - name: Run Falsegreen Trust Audit
        run: falsegreen . --fail-under 90 --github-annotations

3. GitHub Code Scanning (SARIF Import)

Upload findings directly to GitHub Security alerts tab:

- name: Generate SARIF Security Report
  run: falsegreen . --format sarif --output results.sarif

- name: Upload SARIF to GitHub Code Scanning
  uses: github/codeql-action/upload-sarif@v3
  with:
    sarif_file: results.sarif

4. REST API Reference

Integrate with Falsegreen hosted web scanner programmatically:

# JSON Report:
GET https://falsegreen.fly.dev/api/scan/{owner}/{repo}

# SARIF v2.1.0 Report:
GET https://falsegreen.fly.dev/api/scan/{owner}/{repo}/sarif

# SVG Trust Badge:
GET https://falsegreen.fly.dev/badge/{owner}/{repo}.svg
