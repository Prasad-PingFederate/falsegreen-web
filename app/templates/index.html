The ones people argue about

The assertion that guards itself

if is_visible(element):
    expect(element).to_be_visible()
else:
    print("[WARN] not available")

Reads like a careful test. It is a tautology across two lines: the assertion only runs when the element is already known present, and the case where it is missing — the bug the test exists to catch — prints a warning and passes.

The helper that promises

def assert_row_gone(row):
    try:
        expect(row).to_be_hidden()
    except Exception:
        pass

Every call site reads as verified. Nothing is verified. This one shipped in a real codebase for months, and every delete test that called it silently certified itself.

The test that only navigates

def test_change_password(page):
    page.goto("/settings")
    page.fill("#new", "hunter2")
    page.click("#save")

Runs code, ends, passes. It can tell you the app did not crash. It cannot tell you the password changed, and it will stay green after you break the save handler.
