Anti-Pattern Detection Rules

Explore the complete encyclopedia of test patterns that cause suites to pass falsely.

Critical mock-assertion-typo

Mock Assertion Typo

Bare property access or misspelled assertion method on a Mock instance (e.g. mock.assert_called_once without ()).

- mock.assert_called_once + mock.assert_called_once()
High unawaited-expect

Unawaited Playwright Expect

In Playwright JS/TS, async matchers like expect(locator).toBeVisible() return a Promise. Without await, test finishes before matcher executes.

- expect(page.locator("h1")).toBeVisible() + await expect(page.locator("h1")).toBeVisible()
High unawaited-async-call

Unawaited Coroutine Action

Calling async Playwright actions (page.click(), page.goto()) without await in async tests creates unexecuted coroutines.

- page.click("button#submit") + await page.click("button#submit")
Critical constant-condition-trap

Constant Condition Trap

Using assert a == 200 or 201 evaluates to 201 (truthy integer), making the assertion unconditionally pass regardless of a.

- assert status == 200 or 201 + assert status in (200, 201)
Critical swallowed-assertion

Swallowed Assertion Exception

An assertion is contained in a try: ... except: block that catches AssertionError or Exception without re-raising.

try: assert user.is_active except Exception: pass
High assertion-free-helper

Assertion-Free Test Method

A test method executes application driver code but contains zero assertions or verification steps.

@Test void testLogin() { driver.get(url); } @Test void testLogin() { assertEquals("Home", title); }
